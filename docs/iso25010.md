# Relação com a ISO/IEC 25010

A norma ISO/IEC 25010 define 8 características de qualidade de produto de
software. Abaixo, cada melhoria feita na v2 é relacionada com a
característica correspondente. Ajuste o texto com suas próprias palavras
antes de entregar.

## 1. Adequação Funcional (Functional Suitability)
A v1 permitia cadastrar clientes com dados incompletos ou inválidos (nome
vazio, e-mail sem formato válido, idade não numérica), o que significa que
o sistema não cumpria corretamente a função para a qual foi criado. Na v2,
`validar_dados()` garante que apenas dados corretos sejam persistidos.

## 2. Confiabilidade (Reliability)
Na v1, qualquer erro (ex: idade não numérica) derrubava a aplicação com uma
exceção não tratada. Na v2, a exceção `DadosInvalidosError` é tratada
explicitamente e o sistema continua funcionando normalmente, exibindo uma
mensagem ao usuário em vez de falhar.

## 3. Usabilidade (Usability)
A v1 não dava nenhum retorno claro ao usuário quando um cadastro falhava
(ou pior: aceitava dados errados silenciosamente). A v2 exibe mensagens de
sucesso/erro compreensíveis (`flash`) e usa tipos de campo HTML adequados
(`type="email"`, `type="number"`) que ajudam o usuário a preencher
corretamente antes mesmo de enviar o formulário.

## 4. Segurança (Security)
A v1 constrói a query SQL por concatenação de string, permitindo SQL
Injection. A v2 usa consultas parametrizadas, eliminando essa vulnerabilidade.
Além disso, a v1 rodava com `debug=True`, o que exporia detalhes internos
(stack trace) em caso de erro — corrigido na v2.

## 5. Manutenibilidade (Maintainability)
A v1 concentra tudo (rota, regra de negócio, acesso a dados, HTML) em um
único arquivo, dificultando qualquer alteração futura sem risco de quebrar
outras partes. A v2 separa as responsabilidades em módulos (`app.py`,
`services/`, `repository/`), o que facilita localizar, testar e alterar
cada parte isoladamente.
